Dedicate memory systems
Mem0
Fact-centric
Input: messages, scoped by user, agent, or run.
Retrieval : vector search with filters; optional graph memory.
e.g., “Uses SGLang for model serving.”
Graphiti
Temporal knowledge graph
Input: episodes that yield entities and time-aware facts.
Retrieval: hybrid semantic, keyword and graph search.
e.g., uses → SGLang, valid Apr 2026 → present
supermemory
Profile, memory, document
Maintain a user profile along with memory and document
Input: conversations linked to source and time.
Retrieval: profile, memory and document search

Failure modes
Retrieval miss
Relevant memory exists but isn't found.
Context pollution
Too many irrelevant memories enter context.
Memory hallucination
An inference stored as fact: “studying at Harvard” 
becomes “visiting student at Harvard.”
Staleness
An old fact overrides newer information.
Isolation failure
Memory crosses a user boundary. 
Overgeneralization
One event becomes a durable preference.
Persistent prompt injection
Untrusted content returns later as instructions.
Unbounded growth
Size grows with lifetime, so retrieval cost and 
quality degrade.

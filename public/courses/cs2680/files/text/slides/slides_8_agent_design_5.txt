Monolithic harness: one runtime implements 
memory, tools, context, planning and execution
class CodingAgent:
    def __init__(self):
        self.memory   = Memory()
        self.tools    = Tools()
        self.context  = ContextManager()
        self.planner  = Planner()
        self.executor = Executor()
    def run(self, task):
        while not self.finished:
            a = self.planner.plan(task)
            r = self.executor.execute(a)
            self.context.update(r)
Advantages
• Simple to implement and debug
• Minimal communication overhead
• Internal state is easy to share
• Low execution overhead
Disadvantages
• Hard to replace one component
• Components become tightly coupled
• Hard to share infra across agents
• Isolation is hard to enforce
Key characteristic: the agent owns everything, in one runtime.

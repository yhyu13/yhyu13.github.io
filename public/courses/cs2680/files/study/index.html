How this site works

Read it like a deck

Keyboard

  • ← → / Space / PgUp / PgDn - move between slides
  • Home / End - first / last slide
  • F - fullscreen
  • O - slide overview grid
  • T - cycle theme
  • S - presenter window with notes
  • N - notes drawer
  • #/N in the URL - deep link to slide N

Reading

  • Open any deck from the index; the deck header and footer stay put while you read
  • Every deck names its upstream Harvard URL on the final "Source & navigation" slide and in the footer
  • Numbers on a page always come from the course digest; where the published material disagrees with itself, the deck says so rather than picking a side
  • The site works offline from the filesystem - no server, no network

Method

  • The site is generated by build.mjs from a content model derived from the course digest - the HTML is a reproducible artifact, not hand-typed
  • No external script, font or chart library is required to render a page; the vendored asset set is local
  • Screenshot-only source pages are not described; where the published pages disagree, both readings are shown with their source
Provenance. The digest is the tiebreaker: if two published pages disagree, the deck states the conflict instead of silently choosing one.

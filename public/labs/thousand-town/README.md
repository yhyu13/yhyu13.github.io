# 天降筑城 · 千人小镇（离线 Demo）

复刻 B 站《我用AI做了一个千人小镇》里「方块从天而降、落成街区」那一段。

## 怎么打开

- **双击 `index.html`** 即可（`file://` 下即可运行，无任何网络请求、无构建步骤）。
- 若浏览器对本地文件有限制，可在 `demo\` 目录下执行 `python -m http.server 8000`，然后访问 <http://localhost:8000/>。
- URL 上可带种子：`index.html?seed=20260818`。同一编号必得同一座小镇。

## 控件

| 控件 | 作用 |
| --- | --- |
| 时刻滑杆 | 0–1439 模拟分钟，实时改变天光、天空色与窗灯 |
| 1× / 2× / 4× | 时间流速（1 模拟分钟 = 0.625 秒，1 天 = 900 秒） |
| 城市编号 + 重建小镇 | 用新种子重新生成整座小镇 |
| 换一个 | 随机换一座城 |
| 自动环绕 | 相机匀速绕场 |
| p5 图纸层 | 叠加 2D 图纸（网格 / 道路标注 / 楼块轮廓） |
| 重放落块动画 | 从空中重演一次落块 |

鼠标拖拽旋转视角，滚轮缩放。

## 目录

- `index.html` — 全部逻辑（Three.js 3D + p5.js 图纸层），单文件。
- `vendor/three.min.js`、`vendor/p5.min.js` — 从 `source/vendor/` 原样复制的本地库（离线可用）。
